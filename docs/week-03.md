## 1. 문제 후보 3개 / Three problem candidates

> 네 칸이 다 채워지지 않으면 아직 문제가 아니라 막연한 아이디어입니다.
> 사용자는 구체적으로 기입하세요.

| 네 요소 Four elements | 후보 A | 후보 B | 후보 C |
|---|---|---|---|
| 사용자 Who | 지하철 이용객 | 거주지가 다른 멤버 | 야간주행이 잦은 운전자 |
| 상황 When/Where | 사람이 몰리는 출퇴근 시간/만원 지하철 | 거주지가 다른 멤버 간 약속 장소를 정할 때 | 주변 차량을 식별하기 어려운 어두운 도로 주행 상황 |
| 페인포인트 What — 무엇이 **얼마나** |현재 역이 상시 안내 되지 않음, 전광판이 보이지 않는 자리가 존재함. 내릴 역을 확인하기가 어려움|중간 지역을 찾을 때 각자 출발지에서 약속 장소까지 걸리는 시간과 거리를 한 번에 확인하기 어려움.| 주변에 스텔스 차량이 있는 경우 차선 변경 시 충돌위험 존재  |
| 성공 기준 Done | 역 확인이 용이해서 사용자가 내릴 역을 지나치지 않음 | 각자의 거주지에서 중간 지점의 번화가를 찾아 약속 장소로 지정 | 주변 차량의 수와 위치를 사전에 파악 가능하여 사고위험을 줄임 |

**한 문장으로 / One sentence each** — 네 칸을 이어 붙여 소리 내어 읽어 보세요.
형식: **[사용자]는 [상황]에서 [페인포인트] 때문에 [손해]를 본다.**
읽었을 때 어색하면 그 칸이 아직 덜 채워진 것입니다.

- A: 지하철 이용객은 사람이 몰리는 출퇴근 시간에 만원 지하철에서 현재 역이 상시 안내 되지 않는다는 점과 전광판이 보이지 않는 자리가 존재함에 따라 내릴 역을 지나칠 위험이 있다.
- B: 거주지가 다른 멤버는 멤버 간 약속 장소를 정할 때, 각자 출발지에서 약속 장소까지 걸리는 시간과 거리를 한 번에 확인하기 어려운 점 때문에 중간 지점의 번화가를 찾기 어렵다.
- C: 야간 주행이 잦은 운전자는 주변 차량을 식별하기 어려운 어두운 도로 주행 상황에서 주변에 스텔스 차량이 있는 경우 차선 변경 시 충돌 위험이 존재하는 점 때문에 주변 차량의 수와 위치를 파악하기 어려워 사고 위험에 노출된다.

> 무엇을 **만들지는 쓰지 않습니다.**  기능은 4~5주차에 정합니다. / Describe the problem, not the solution.

> 성공 기준은 지금은 말로 써도 됩니다. "몇 초 이내" 같은 정확한 문장으로 다듬는 것은
> 4주차에 EARS로 합니다. / Plain words are fine for now — we formalise these next week.

## 3. 확인할 가정과 확인 계획 / Assumptions and how to check them

> 지금 사실이라 믿고 있지만 아직 확인하지 않은 것을 적고, **어떻게 확인할지** 정합니다.


**먼저 고르세요 / Pick the right method**

| 방법 | 이럴 때 씁니다 |
|---|---|
| **인터뷰** | 물어야만 알 수 있는 것 — 기억, 판단, 겪은 일, 왜 그렇게 했는지 |
| **관찰** | 가서 보면 알 수 있는 것 — 줄 길이, 걸리는 시간, 실제로 하는 행동 |
| **기존 데이터** | 이미 어딘가 쌓여 있는 것 — 학사 통계, 게시글, 앱 리뷰 |
| **직접 해보기** | 우리가 재현할 수 있는 것 — 그 과정을 실제로 한 번 해본다 |

> *Don't interview for what you can observe.*

| # | 후보 | 우리가 사실이라 믿는 것 | 방법 | 누구에게 / 무엇을 | 담당 | 기한 |
|---|---|---|---|---|---|---|
| 1 | A | 전광판으로 내릴역을 확인하기 어려울 것이다 | 직접 해보기, 관찰 | 지하철 사용자 / 전광판을 보기위해 하는 행동 확인 |  |  |
| 2 | B | 약속 장소로 중간 지역을 선호할 것이다. 중간 지역 선정 과정에서 거리, 시간을 매번 파악하기 번거로울 것이다. | 직접 해보기 | 약속 장소를 정하는 멤버 / 약속 장소를 정하는 과정 전반 |  |  |
| 3 | C | 야간 주행 중 주변 차량 파악이 어려워 사고 위험을 겪었을 것이다. | 직접 해보기 | 야간 운전자 / 사고 발생 위험 존재 여부 확인 |  |  |

> **인터뷰를 쓴다면** 팀원 외 3명 이상,이 문제를 겪고 있는 당사자를 포함하세요.
> 3명은 **주제를 거르기 위한 최소치**입니다. 통계가 아닙니다.
> 3명 중 2명이 인정했다고 해서 "66%가 문제를 겪는다"고 쓰면 안 됩니다.
> 숫자로 주장하려면 훨씬 많이 필요합니다.(설문지를 통한 결과 도출) / Three people is a filter, not a statistic.

**지금은 어떻게 하고 있는가 / What do they do today?**

> 불편해도 사람들은 이미 나름대로 하고 있습니다. 예) 문제를 공유하고 싶은 문제가 있을때 카톡 전송, 엑셀 파일 메일로 보내기, 그냥 포기하기 — **도구가 아니어도 답입니다.**

- **지금은 어떻게 하고 있는가** (도구가 없으면 "그냥 포기한다"도 답):
- 1번 사례 : 지도 앱을 켜서 GPS로 현재 어느 역에 있는지 확인한다. 
- 2번 사례 : 각자 이동시간을 검색하고 카톡으로 공유해서 적절한 장소를 정한다.
- 3번 사례 : 주의하면서 운전을 한다.
- **그래서 충분한가** — 충분하지 않다면 무엇이 부족한가:
- 1번 사례 : 충분
- 2번 사례 : 충분X, 이유 : 완벽하게 같은 이동시간이 아닌 이상 의견이 갈리기도 함
- 3번 사레 : 충분X, 이유 : 차가 안보이거나 갑자기 사고를 낼 수 있다
