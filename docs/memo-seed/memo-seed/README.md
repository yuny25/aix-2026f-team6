# memo-seed

AI+X 공학융합프로젝트 2주차 실습용 저장소입니다.

간단한 메모 서비스의 일부입니다. 목록 조회, 단건 조회, 생성 기능이 구현되어 있습니다.

## 파일 구성

| 파일 | 내용 |
| :-- | :-- |
| `schema.sql` | 데이터베이스 테이블 정의 |
| `service.js` | 데이터베이스 접근 로직 |
| `routes.js` | HTTP 엔드포인트 |
| `CONVENTIONS.md` | 프로젝트 규약 |

## 2주차 과제

**메모 검색 기능을 추가하라. 제목과 본문에서 키워드로 찾을 수 있어야 한다.**

조별로 에이전트에게 주는 자료가 다릅니다. 활동지(`docs/week-02.md`)의 지시를 따르세요.

## 참고

실행 환경 구성은 이번 실습의 목적이 아닙니다. 코드를 직접 돌려보지 않아도 됩니다.

생성된 코드를 **읽고 판단하는 것**이 오늘의 과제입니다.

- 기존 파일과 스타일이 같은가
- 실제로 존재하는 컬럼 이름을 썼는가
- `CONVENTIONS.md`의 규칙을 지켰는가
- `user_id` 조건이 들어 있는가
