## 팀명·팀원·학부 / Team, members, department
 - 팀명 : 6팀
 - 팀원 : 장윤영, 김현승, 이다현, 박정하 / ICT융합학부

## 연락 규칙 / Contact rule — 어디로, 몇 시간 내 응답
 - 카카오톡으로 연락
 - 4~5시간 안으로 응답
 - 만약 5시간이 넘을 시 사유 제출(ex 수업시간, 알바)


## 회의 규칙 / Meeting rule — 요일·시간·불참 처리
 - 요일 : 평일 or 주말
 - 시간 : 저녁
 - 불참 처리 : 회의 30분 이상 지각시 불참 처리(ex 사유 있을 시 인정 가능)
 - 지각 시 : 3회 지각 시 1회 불참으로 취급


## 기여 규칙 / Contribution rule — 1인당 주 최소 작업량
 - 최소 각자 배정된 일만 해결


## 갈등 처리 / Conflict rule — 의견이 갈릴 때
 - 둘의 합의점을 찾아 선정
 - 만약 합의점을 못찾을 시 다수결로 선택


## 마감 규칙 / Deadline rule
 - 해당 날짜 자정까지, 이후 제출은 지각


## **팀 공용 언어 / Working language** — 회의 언어 / 기록 언어
 - 한국어


## AI 사용에 대한 팀 합의 / Team agreement on AI use
 - 자유롭게 사용 가능


## 성찰 / Reflection — 가장 걱정되는 것
 - 결과물이 잘 나올지 염려스러움
